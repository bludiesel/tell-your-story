# Before you start

This is a workbook, not a slide deck. It opens like a book, turns page by page,
and is meant to be read at your own pace.

Work through it in order. Each spread covers one idea.

---

>> The basics
> the basics

## Why this matters

Reticulated gas reaches hundreds of buildings. Done right it is invisible to the
customer. Done wrong it is dangerous.

The four rules on the next page apply to **every** job, regardless of size.

:::tip Keep this handy
The rules never change. If a job seems to need an exception, stop and ask.
:::

:::sticky Remember
Ask the supervisor before you assume — every time.
:::

---

>> The rules
> rule one

## Isolate before you open

Close the upstream valve first, then prove the line is dead before opening
anything downstream.

- Confirm the valve is the right one
- Watch the gauge fall, do not assume
- Tag it so nobody reopens behind you

:::sticky
The gauge is the proof. Your memory isn't.
:::

> rule two

## Never work alone on a live line

A second person is not a formality. They are the one who calls it in when you
cannot.

:::warning If you are alone
Stop. Reschedule. There is no version of this that is worth it.
:::
